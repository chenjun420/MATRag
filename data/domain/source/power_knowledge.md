# 电源领域通用知识

## 基本电学关系

欧姆定律: 导体两端电压 V 与通过电流 I 成正比, V = I × R; 电阻 R = V / I; 电流 I = V / R。
直流功率 P = V × I。纯电阻电路中 P = I²R = V²/R。
焦耳定律: 电流通过导体产生的热量 Q = I²Rt。
串联电路电流处处相等, 总电压等于各部分电压之和, 总电阻 R = R1+R2+…; 并联电路各支路电压相等, 干路电流等于支路电流之和, 1/R = 1/R1+1/R2+…。
电阻温度系数: 金属导体温度升高时电阻增大, 灯丝冷态电阻小于热态。

## 交流与功率因数

功率因数 PF = 有功功率 P / 视在功率 S = cosθ; S² = P² + Q²; 无功 Q = V_rms·I_rms·sinθ。
单相视在功率 S = V_rms × I_rms; 对称三相 P = √3 × U_line × I_line × cosφ。
开关电源输入为整流+电容, 电流呈脉冲状, 功率因数低; PFC 校正后 PF 可达 0.99。EN61000-3-2 要求 75W 以上电器限制谐波。

## 电源效率与损耗

转换效率 η = P_out / P_in × 100%。损耗 P_loss = P_in − P_out。
交流输入功率 P_in = V_in × I_in × PF。
MOSFET 导通损耗 P_cond = I_avg² × R_DS(on) × D; 开关损耗与 tr/tf 和频率成正比。
电容 ESR 损耗 P = I_rms² × ESR; 高 ESR 降低效率并增大纹波。
降压变换器占空比 D = V_out / V_in; 输入电流 I_in = D × I_out。

## 热设计

温升 ΔT = P_loss × R_th; 结温 T_j = T_a + P × R_th。
铝电解电容寿命: 温度每降低 10℃ 寿命约翻倍 (Arrhenius 近似); 纹波电流过大同样加速寿命衰减。
功率器件需要电压/电流降额设计; 电容需要电压降额。

## 保护逻辑常识

过压/过流/过温保护的strip点必须高于恢复点, 两者之差为保护回差; 回差过小会引起保护抖动。
输出过流保护常采用打嗝(hiccup)方式: 保护后尝试自动恢复, 长期短路不损坏电源。
告警阈值须低于保护点并留安全余量 (如过流告警 ≤ 过流保护点 − 0.5A, 过温告警 ≤ 过温保护点 3℃)。
过压去除后能自恢复; 输入欠压恢复需高于欠压保护点一定回差。

## 测试与工装

测量仪器精度应优于被测公差的 1/3 (测量系统分析原则); 公差链合成可用均方根法 RSS: 总公差 = √(Σ分量²)。
纹波测试使用 20MHz 带宽限制, 并联 10uF 电解电容与 0.1uF 陶瓷电容。
pogo pin 探针: Ø0.5mm 约 1A (信号), Ø1.0mm 2~3A, Ø1.5mm 3~5A, Ø2.0mm 5~6A, Ø2.5mm 以上 10~40A (大电流)。
探针接触电阻典型 20~50mΩ, 高电流型 10~30mΩ; 探针寿命标称基线 10 万次插拔, 实际工况下有效寿命约 5 万至 15 万次。
低电阻测量采用四线开尔文接法消除线阻影响。
通道数规划: 所需通道数 = ceil(目标产能 × 单次测试时间 / 可用工作时间)。

## 测量系统与探针寿命

测量系统分辨率须满足 10:1 规则: 分辨率 ≤ min(被测公差, 过程变差)/10, 否则过程变差无法被分辨。
量具重复性与再现性 %GRR 判定: ≤10% 可接受, 10%~30% 视应用条件, >30% 不可接受。
四线 Kelvin 测接触电阻: 力线与感线必须在被测接触点汇合, 夹具引线电阻被完全消除; 半 Kelvin(在探针插座处分离)不消除接触电阻, 仅当接触电阻 < 被测值/10 时可用。
公差堆叠两种算法: 最坏情况 WC = Σ|tᵢ|; 均方根 RSS = √(Σtᵢ²), 统计独立假设下约为最坏情况的 1/√n。
大电流探针最小中心距随电流上升: 30A 级 ≥6.35mm(0.25"), 20A 级 ≥4.45mm(0.175"), 信号针可至 0.25mm 级。
探针相邻间隙不足时采用交错排布(stagger), 有效间隙可由"节距 − 针径"提升为"节距 − 半针径", 允许用更大直径探针降低工装成本。
探针寿命: 标称基线 100,000 次, 实际工况下有效寿命通常 50,000~150,000 次; 失效模式含弹簧疲劳、镀层磨损、微动腐蚀、异物侵入、过流、永久变形。
探针选型须按实际排产循环数 × 安全系数(2~3)留余量, 不得直接选规格书最高值。
接触电阻随插拔磨损增大, 产测上限须留时间衰减余量并建立周期性复校(建议每班次或每数万次插拔)。

## DC-DC 拓扑与实测判据

降压占空比 D = Vout/Vin; Boost 占空比 D = 1 − Vin/Vout; 电感纹波电流 ΔI_L = Vout·(Vin−Vout)/(Vin·L·f_sw)。
输出纹波 = 电容纹波 ΔV_cap = ΔI_L/(8·f_sw·C_out) + ESR 纹波 ΔV_ESR = ΔI_L·ESR; 提高开关频率或增大输出电容是降低纹波的主要手段。
电感峰值电流 I_pk = Iout + ΔI_L/2, 有效值 I_rms = √(Iout² + ΔI_L²/12); I_pk 不得超过电感饱和电流 I_sat, 否则满载进入饱和。
输出电容选型 C = ΔI_L/(8·f_sw·ΔV_ripple); 实际纹波电流有效值须 ≤ 电容额定纹波电流, 超额引起自热并按 Arrhenius 加速老化。
隔离型变压器匝比 n = Np/Ns, 产测变比须在标称 ±(2~5)% 内, 偏差过大提示匝间短路或磁路饱和。
启动: 软启动限制输出浪涌, 启动过冲 ≤ 1~5%·Vout, 启动时间须 ≤ 规格值。
负载瞬态: 负载阶跃下输出偏移 ≤ ±3~5%·Vout, 恢复至 ±100mV(或 ±2%) 恢复带的时间 ≤ 100~500µs; 判读须给出阶跃幅度、斜率、恢复带三个条件。
输入瞬态 (line transient) 与负载瞬态为两类独立试验: 输入阶跃下输出偏移 ≤ ±2%, 恢复 ≤ 100µs。
保持时间 (hold-up): 断电后输出维持 ≥90% 标称的时间, 通用要求 ≥16~20ms; 母线电容 C = 2·P·t/(η·(V1²−V2²)), 须在最低输入电压下判定(储能按 V² 变化)。
浪涌电流: 上电瞬间受 NTC/限流电阻/继电器限制, 并与输入保险丝 I²t 配合, 重复插拔与低温工况须分别验证。

## 电压调整率与输出精度

电压调整率 = (V_低线 − V_高线)/V_标称 × 100% (输入变化, 负载恒定)。
负载调整率 = (V_空载 − V_满载)/V_标称 × 100% (负载变化, 输入恒定)。
两者须在恒流/恒压条件下独立测量, 不可互相替代; 模块电源典型规格 ≤0.5%~1%。
输出精度: 电压/电流实测偏差 ≤ ±(0.5~1)% 读数 + ±0.5% 满量程, 判据余量须大于仪器精度 2 倍。

## 效率与功率判据

效率 η = Pout/Pin × 100%; 效率测试在额定输入下于 25%/50%/75%/100% 负载点分别测量, 取最小值判定。
功率测量须用电压/电流同步采样的功率分析仪(精度 ≤±0.5% 读数), 不同步将因纹波相位误差导致效率读数失真。
空载输入功率 ≤ 规格值 (模块典型 0.3~0.5W), 反映待机损耗。
功率平衡自检: 任意工况 Pout ≤ Pin, 若 Pout > Pin 属数据采集/判读错误, 须重测而非判产品异常。

## 保护功能矩阵

五类保护必备: 过压 OVP、过流 OCP、过功率 OPP、过温 OTP、短路 SCP; 每类须明确触发条件、动作方式(关断/限流/降额)、恢复方式(自恢复/锁存)、上报方式(遥信/故障码)。
OVP: 宽输出可调电源须用跟踪式 OVP (保护点 = 设定值 × 110~135%), 固定 OVP 在高设定值下钳位点过高可能损坏负载。
UVLO: 输入低于关断阈值关断输出, 恢复到更高启动阈值后重启; 典型 8.7V 启动 / 8.1V 关断 (回差 0.6V); 阈值须给出全温区最小/最大/典型三档限值, 典型值不可用于判定。
UVLO 回差须大于器件启动电流引起的供电压降, 否则高阻抗或长线供电时会反复启停。
工作范围与启动范围分层有序: 最低工作电压 < UVLO 启动阈值 < UVLO 关断阈值, 欠压告警点须高于最低工作电压且低于关断点。
过流保护四模式: hiccup 打嗝 (数百 ms~数 s 重试, 故障消除后自动恢复)、恒流限流、折返 foldback (短路电流 0.2~0.5 倍限流点)、锁存 latch-off (需人工/上电复位)。
hiccup 保护须每周期配软启动, 短路期工作频率大幅下降(数百 Hz), 故障恢复后无过冲重启。
保护点精度: 实测值须落在标称 ±5% 容差带内, 判定余量须大于测量仪器精度 2 倍。
回差通用下限: 回差 ≥ max(设定值 × 1%, 输入噪声峰峰值 × 2); 回差过小引起保护抖动, 过大形成保护死区。
告警分级: 1 预警 (仅告警) → 2 降额 (限功率运行) → 3 停机保护 (关断), 阈值须逐级递进; 告警阈值须低于保护点并留余量。
多告警并发仲裁: 按严重度排序, 最高级优先上报; 保护动作优先于告警上报。
输入反接保护: DC 输入产品反接不损坏(串二极管或理想二极管控制器), 反接消除后恢复正常。
输出反灌保护: 带电池母线或支持并联的产品须用理想二极管/ORing MOSFET 防反灌, 避免已关断模块成为反向电流通道。
远程感测 (remote sense): 补偿输出线与连接器压降, 感测线开路时退回本地感测、短接时须设限保护, 产测须覆盖异常用例。
数字控制器看门狗: WDT 超时进入安全态(关断或开环限功率)并置故障遥信。
故障锁存: 最高级故障锁存并记录故障码, 复位时若故障源仍存在须重新触发。
遥测采样开路/断线须报故障或钳位至安全值 (fail-safe), 不得继续输出有效测量值。
N+1 冗余: 单模块故障自动退出并置故障遥信, 母线不中断, 剩余模块须能承担全载。
并联均流: 各模块分担电流偏差 ≤ ±5%; 无源二极管 ORing 不保证均流, 仅保证冗余切换; 均流偏差 >±10% 须置故障并退出该模块。

## 安规产测项

绝缘耐压 (hipot): IEC 62368-1 基本绝缘 (输入对地) 2500Vdc, 加强绝缘 (输入对输出) 4000Vdc; 须在正负两个极性下各进行, 型式试验与生产线例行试验均须执行。
耐压试验设备须具备过流保护, 试验后须充分放电; 例行试验电压可低于型式但不得低于规定值。
爬电距离与电气间隙: 按工作电压峰值、绝缘类型、过电压类别与污染等级查表; 基本绝缘 1500V 峰值 → 0.5mm、2000V → 1.0mm、2500V → 1.5mm、3000V → 2.0mm; 加强绝缘取 2 倍; 海拔 >2000m 须乘修正系数 (5000m 取 1.48)。
Y 电容容值由漏电流反推: C = I_leak/(2π·f·V), 按最恶劣工况 (60Hz, 264Vac); IEC 62368-1 IT/AV 限值手持 0.25mA、移动 0.75mA、固定 3.5mA。
Y 电容耐压分级: Y1 用于一次侧到可触及非接地部件 (8kV 测试), Y2 用于一次侧到可触及已接地部件 (5kV 测试); Y 电容失效模式必须为开路。
保险丝 I²t 配合: 保险丝分断 I²t 须显著大于被保护器件 I²t, 典型配合比 ≥10 倍。
接触电流/漏电流: 正常状态与单一故障状态各测, 且极性反转各测一次(整流充电峰值影响读数); Class I 信号/连接器限 0.25mA/0.5mA 类。
接地连续性: 用 ≥10A 大电流低电阻法测量并做零线补偿(扣除测试线电阻), 判据 <0.1Ω。
安规测试顺序: 上电前先测绝缘电阻/接地阻抗(排除短路) → 耐压 → 上电功能与保护 → 上电后复测; 顺序颠倒可能在失效品上施加危险电压。

## 遥测、遥信与遥控

遥测精度: 电压/电流读数误差 ≤ ±(0.5~1)% 读数 + ±0.5% 满量程; 分流器精度高(0.1~2%)但无隔离且损耗 I²R, 霍尔隔离但精度 0.9~2% 且温漂 50~300ppm/K。
遥测采样率须覆盖开关纹波频率的 10 倍以上或先经低通滤波, 否则高频纹波混叠为低频虚假读数; 采样链路传播延迟 (霍尔 1~3µs) 须与保护动作时间匹配。
遥信去抖: 数字输入须设去抖滤波 (工业隔离输入典型 0/10/30/100ms, 低速通道内置 4µs 低通); 去抖时间须短于上报时延要求且不短于实际接点抖动时间。
NTC 换算: R(T) = R₂₅·exp(B·(1/T − 1/298.15)), B 典型 3435~3950K; 分压电阻须低温漂(≤50ppm/K)精密电阻; 测温点须贴近发热器件而非只测环境。
温度遥测精度: R25 ±1% + B 值 ±1% + 分压电阻 ±0.1% 合成通常 ≤ ±1°C, 高温段 R 值小使相对误差放大。
本地/远端切换: 远端使能时本地操作须失效或明确提示; 遥控关断走与本地相同的软停/保护流程, 不得直切功率级。
设定值限幅: 遥控设定范围须内嵌于硬件保护范围 (设定上限 ≤ OCP 点 − 余量), 不得因设定使电源进入自身保护。
设定-回读一致性: 下发设定值后回读实际值偏差 ≤ 设定精度带, 须在 0%/50%/100% 三点验证。
遥控命令时延: 从命令发出到输出建立 ≤ 规格 (串口典型 200~500ms, 含软启动); 通信应答时间不等于执行完成时间。
告警上报时延 ≤ 1s; 与保护动作时延 (短路 <100µs 级) 是两个独立指标, 不可混用。
遥信极性: 0/1 语义、常开/常闭触点、失效安全(失电默认状态) 须标注与实现一致; 常见错误是声明常开但实现失电即报故障。
通信接口产测: RS485 验证地址唯一性与帧校验, CAN 验证误码率与终端电阻, 数字量 I/O 逐点通断; 连续 N 次成功率 100%, 出现偶发错误即判不合格。
告警输出接口: 干接点/光耦/推挽电平须匹配, 隔离等级与主功率一致(同为加强绝缘时不得降级), 干接点须标触点容量与寿命。

## 产测校准与降额

输出标定: 两点或多点标定 (至少 0% 与 100%), 标定后残差 ≤ ±0.5%, 判定余量 > 基准源精度 2 倍; 标定数据写入非易失存储并在重启后保持。
电容电压降额: 实际工作电压 ≤ 额定 × 80%, 高温更严; 降额不足直接按 Arrhenius 缩短寿命。
半导体结温降额: T_j ≤ 额定最高结温 − 20℃, 温升 ΔT = P × R_th 复核。
热阻链路: R_th,ja = R_th,jc + R_th,cs + R_th,sa 串联叠加; 产测可由实测温升反推实际热阻 = ΔT/P_loss, 与设计值偏差过大提示导热界面劣化。
环境温度联动: 高温工位输出能力按降额曲线降低, 判据须按实测环境温度查对应降额值, 不用额定值判定。

## 低线输入降额 (分段输出功率)

规格书常按输入电压分段给出输出功率上限, 例如 "输出功率 600W; 90~176Vac: 400W; 176~286Vac: 600W"。
110Vac 这类低压标称点落在低线段时, 满载输出电流必须按该段功率上限反算: I = P_低线段 / V_out,
严禁沿用高压段的额定电流 (上例 400W / 54V = 7.4A, 而非额定的 11.1A)。

物理原因: 低线时为维持功率, 输入电流升高, EMC choke 等阻性损耗按电流平方增长, 叠加输入滤波/整流/PFC 过热,
故厂商普遍对 100Vac 以下按 1%/V~2%/V 线性降额, 90Vac 时最大可降约 20%。

产测要点:
- 判据上限必须取该输入电压对应的降额值, 不得用额定功率/额定电流
- 输出过流保护点在低线段同样会下移 (如输入 <176Vac 时过流点下限由 12A 降到 8.1A),
  判据与保护点必须取同一输入电压条件的值, 不可交叉引用不同条件下的数值
- 该降额表若只存在于规格书备注文本中, 属未结构化数据, 须人工确认后再用于判定

## 安规与可靠性

绝缘电阻: 正常大气压、相对湿度 90%、直流 500V 下 ≥ 2MΩ。
绝缘耐压: 输入对输出 4000Vdc/1min, 输入对地 2500Vdc, 输出对地 500Vdc, 漏电流 ≤ 10mA。
接地阻抗 < 0.1Ω; 接触电流: 保护地端 < 2.5mA, 输出端 < 0.5mA。
可用度 A = MTBF / (MTBF + MTTR)。
安规标准: IEC/EN/UL 62368-1, GB 4943.1。

## 控制环路稳定性

相位裕度 PM: 交越频率处环路相位滞后距 -180° 的余量, 单位 度。增益裕度 GM: 相位首次达到 -180° 处环路增益低于 0dB 的余量, 单位 dB。交越频率 fC: 环路增益幅值降到 0dB 的频率。
通行最小判据: PM ≥ 45° 且 GM ≥ 10 dB。Hartman(DesignCon 2002)明确这是 customary; onsemi TND352-D、NXP AN4661、Microchip AN1452 四家独立厂商给出一致下限。这属工程惯例, 不是 GB/IEC 强条 —— 本型号的下限以规格书/方案为准, 不得用行业惯例替代。
fC 上界: fC < fSW/2。onsemi TND6238 与 NXP AN4661 一致; 环路注入测量的扫频上限同样不得超过 fSW/2, 否则 PWM 采样效应使读数失真。
fC 与 fSW 的设计比值无定论: ADI MAX20796 取 fSW/5, 电源电子教科书取 fSW/10~1/20。比值是设计取舍(瞬态响应速度 对 噪声与开关纹波注入), 须按方案确定, 不得当通用常数硬编码。
裕度判据的适用边界: PM/GM 只在单一交越频次、且交越后增益以 20 dB/decade 或更陡单调下降时可靠。Type III 补偿或含 DSP 的环路即使 PM 达标, 若交越后幅值曲线平缓而相位继续下滑, Nyquist 曲线会逼近 (-1,0) 点而系统仍不稳 —— Hartman 明确指出该失效模式常见。裕度达标不等于稳定, 须回看完整 Bode/Nyquist 曲线。
光耦环节: CTR 离散(典型 80~160%)与结电容(约 10~30nF)引入中频极点, 会额外压低相位裕度; onsemi 建议最坏情况按 GM ≥ 15 dB 量级留裕度。
实测方法: 注入法(加变压器断开环路后扫频), onsemi TND6238 给出实现; 亦可用网络分析仪测 Return/Injection 后反算开环。注入法在环路带宽外需外推。
测量前提: 被测环路必须先建立稳定; 扫频前应把补偿器带宽压低以保证稳定, 或延长软启动时间避免过冲触发过压保护, 否则测量本身会扰动被测对象(onsemi TND6238)。
交叉判读: 交越后若相位继续下滑而增益曲线平缓, 即使 PM/GM 数值达标仍应重新设计; 反之 Bode 图上裕度不足但 Nyquist 轨迹远离 (-1,0) 时也未必不稳 —— 判据成立与否取决于环路形状, 不只是两个数字。

## 冷却方式与热阻取值

冷却方式决定热阻取值: 同一器件的 θJA 随冷却方式与风速变化。数据手册给的 θJA 是 still air(自然对流)值, 不得直接用于强制风冷工况的结温校核; 强制风冷须取该风速下的热阻, 或用风冷改善系数把自然对流热阻折算到风冷工况。
自然对流的热分配: 散热片约 70% 热量靠对流、30% 靠辐射(Infineon AN-1057); 高海拔空气变稀, 70% 高度以上辐射占比升到 70~90%。
强制风冷的热分配: 180 LFM 时辐射份额降到 2~7%, 对流成为唯一主项; 层流与紊流的过渡约在 180 fpm(TI SNVA509A)。
风速对热阻的实测影响(NXP AN2601): 同板 3×3 阵列中心器件, 自然对流 21.6°C/W, 100/200/400 ft/min 依次为 18.8 / 17.4 / 15.6°C/W; 同板 9 器件满载时 0.5 / 1.0 / 1.5 / 2.0 m/s 依次为 47 / 34 / 27 / 23°C/W。邻器件发热会显著抬高本器件温度, 密集布局比风速本身影响更大。
试验条件不同则 θJA 不可比: 自然对流按 JESD51-2A(静止空气, 1 立方英尺箱体, 板水平放置), 强制对流按 JESD51-6(风洞, 板垂直于气流, 常用风速 100~600 LFM, 200 LFM 约合 1 m/s)(Renesas TB379)。引用数据手册 θJA 前必须先确认该值属于哪套条件。
散热片几何: 热阻反比于散热面积 —— 散热面积减半需体积增到约 4 倍; 阳极黑化可降约 4%(自然对流下更明显)。强制风冷时体积才是主导因素(Infineon AN-1057)。
风冷布置: 强制风冷的风道应顺应自然对流的气流方向, 不得阻塞散热片风道; 风机装在侧面顺翅片方向吹与装在顶部中心向下/向上吹, 效果不同, 按实际安装方式取值。
风冷降额曲线: 数据手册通常分别给 free air 与 forced air 两条降额曲线(典型以 18 CFM 风机为例)。引用降额值必须注明所用冷却方式与风速 —— 用错曲线的直接后果是满载高温点判错。
风冷工况的判据归属: 上述风速阈值与热阻数值均为厂商应用笔记给出的实测/工程数据(industry 级), 非标准强条; 具体型号的热判据以该型号规格书与方案为准。
## 测量不确定度与量具能力

测量能力是产测判据成立的前提: 同一判据(如输出精度 ±1%)在不同量具能力下得出的结论可信度完全不同。系统已能给出 %GRR 的结论判据(见量具重复性与再现性), 但结论所依据的量具能力体系必须能显式声明。
合成与扩展不确定度: 各输入量的标准不确定度按方和根合成得 u_c; 扩展不确定度 U = k × u_c, 常用 k=2(约 95% 置信)。相对标准不确定度低于约 15~20% 时可按正态分布取 k=2(ISO 14253-1 术语 3.16/3.17, EURachem QUAM 4.3)。k 必须显式给出, 不得隐含为 2。
测量能力指数 Cm = 公差 /(倍数 × 标准不确定度), ISO/TR 14253-6:2012 术语 3.8 明确倍数取 4 —— 即被测公差至少应为标准不确定度的 4 倍。**与 TUR 的约定差异**: ANSI/NCSLI Z540.3 定义 TUR = 公差/扩展不确定度, 与 Cm 差一个覆盖因子( TUR = Cm × k ), 两者不可混用, 引用时须说明用的是哪一个。
保护带与决策规则: 测量不确定度会使落在规格限附近的测量结果无法判定合格与否。ISO 14253-1:2017 的默认决策规则是在规格限上叠加 100% 的 U 作为保护带, 对应 95% 的符合概率。产测判据若直接用规格限作门限而不声明保护带, 等于默认接受 2.5% 的误判概率(k=2 时)。
公差、倍数、不确定度必须取同一被测量、同一工况的值: 跨工况交叉引用会把不同温度或不同负载点的数字拼在一起, 得到看似合格实则不可比的结论。
量具能力不足时的处置: 不得靠放宽判据来通过, 应升级量具或降低测量要求; 判据门限须由能力指数反推, 而不是先定门限再宣称能力足够。

## ADC 与频谱测量约束

量化步长: 1 LSB = 满量程输入范围 / 2^位数 (ADI MT-229 式3)。理想 N 位 ADC 的最大量化误差为 ±0.5 LSB, 量化误差等效为峰峰值 LSB 的非相关锯齿波, 故均方根量化噪声 = LSB/√12 (即 LSB/(2√3))。产测按 LSB 判分辨率时须用被测信号的实际跨度, 不能直接套满量程 —— 用满量程算出的 LSB 会低估误差。
量化噪声的白噪声假设有前提: 只有量化误差与输入不相关时才成立。若采样时钟与被测信号成谐波关系(整数量化), 噪声能量会集中到信号各次谐波上, 频谱底噪不再平坦(ADI MT-001 用 12 位 80MSPS 4096 点 FFT 实例说明: 基频 2MHz 时最差谐波比基波低约 77dB, 而输入偏到 2.111MHz 后 SFDR 升到约 93dBc)。此时不得用 LSB/√12 判读底噪, 必须先确认相干性。
孔径抖动: 采样时刻的逐次变动对交流输入产生的 rms 电压误差 = 2π·f_in·t_a·A (ADI AN-501 式4)。**抖动造成的 SNR 上限与转换器位数无关** —— 位数再高也补不回时钟抖动(ADI AN-501: 250MHz 输入下 1ps 抖动就把 SNR 限到 56dB; ADI MT-200: 100MHz 满量程输入下 14 位 ENOB 要求 rms 抖动 ≤125fs)。产测判读高频小信号前须先用低频点扣除量化噪声与 DNL 再解算抖动。
有效位数: ENOB = (SNR_dB − 1.76)/6.02, 由理想 N 位转换器 SNR = 6.02N+1.76dB 反解(ADI MT-001 式9、MT-200)。该式只在量化误差与输入不相关、且 SNR 于 dc~fs/2 全 Nyquist 带宽内积分时成立; 若只对关心的带宽做数字滤波, 须另加处理增益修正, 否则 ENOB 被高估(ADI MT-001 式10)。
采样率下限: 被测信号最高频率须低于采样率的一半(Nyquist), 否则带外频率折叠成带内虚假读数。遥测链路的采样率判据见「遥测、遥信与遥控」一节, 仪表链路的判据须另行声明, 两者不互相替代。
频谱泄漏与窗函数: 记录长度与被测频率不对应时, 能量会泄漏到邻近频线。频谱测量须声明记录点数、窗函数与是否做相干平均; 泄漏造成的虚假谐波不得判为产品异常。
相位误差: 采样时刻的系统性偏移(孔径延迟)与逐次变动(孔径抖动)是两个不同量, 前者产生固定相位偏移, 后者产生噪声。产测若关心相位量(如并机相位、纹波与信号的相位关系), 须分别声明, 不可用抖动值代替延迟值。

## 并联均流与下垂法

并联均流判据(±5% 这类结论)不足以独立成立: 均流精度由输出电压设定精度与下垂斜率共同决定, 只给结论不给这两个参数, 判据无法复核。
下垂法原理: 人为提高各模块的输出阻抗, 使输出电压随负载电流下垂(典型空载 +2.5% 到满载 −2.5%)。并联时各模块被拉到同一输出电压, 因斜率相同而自然分流。属开环方案, 不需均流母线, 但牺牲负载调整率。
均流误差公式: 两机电流差 ΔI = ΔV_SET/ΔV_SLOPE, 相对均流误差 ε = ΔV_SET/(ΔV_SLOPE × I_RATED) (Vox Power DOC-APN-006-02 式1~式3)。并联台数增加时, 任意两机之间的误差不超过按两机算出的上限。
设定精度决定均流精度: IEEE PELS 实测分析给出量化关系 —— 输出调节范围 ±5% 配设定精度 ±1% 时, 满载均流误差可达 33.3%; 要压到 10% 以内, 设定精度须优于 ±0.35%。所以常见的 ±5% 均流只在设定精度与下垂量同时满足时才成立。
产测数据能收窄估计: Vox Power 给出算例 —— 最坏情况 ΔV_SET=±0.01·V_NOM 配 ΔV_SLOPE=±0.025·V_NOM/I_RATED 时 ε=±40%, 而 25°C 下两倍标准差的实际 ΔV_SET=±0.003·V_NOM 时 ε=±12%。引用均流判据时须标明用的是最坏情况还是统计估计。
下垂量的取舍: 下垂量取大可改善均流但直接损失负载调整率, 二者不可兼得; 且设定精度须在全温度与全时间范围稳定, 只在常温标定合格不代表全温区合格。
外部阻抗不可忽略: 下垂法受模块间连线与接插件阻抗影响(长线、细线、低熔点接线端子都会抬高等效下垂斜率并使均流变差)。产测须在最终线束状态下判定, 不得用短金线测试结果代表实际装夹。
并联台数不等于能力倍数: 各模块电流无法完全均分, 并联后的最大可用输出电流小于「单机额定 × 台数」, 须按实际均流误差做功率降额(Vicor 设计指南 §5 亦指出并联系统会因电流集中导致单模块过载与可靠性下降)。

### 产测执行方法 (均流不平衡度测量)

工况点: 并联系统在额定电流的 10% / 25% / 50% / 75% / 100% 五个负载点各
测一轮; 每点稳定运行 ≥5min 再同步读数, 同一工况重复读数取平均(电力系统
用直流电源装置行业标准做法; 轻载点受自耗电流占比影响, 判定限值通常放宽).

判据公式: 均流不平衡度 = (|Ii − Ī|max / Ī) × 100% —— 单模块输出电流与
各模块平均电流之差的最大绝对值比平均电流. 半载及以上负载区间常规限值
±5%, 轻载放宽(参考 ≤±10%); **本型号的限值以规格书/需求方澄清为准**, 这里
只给业界常规量级(Glary AN: 并联电流容差 ±5% / 带均流的电压容差 ±1%.

前置校准: 并联前须逐台单独测输出电压整定范围/稳压精度/限流特性 —— 单机
工作点漂移会直接劣化并机均流, 测出偏离先整改再并机.

动态均流: 半载稳态下对总负载施加 50%→100% 阶跃, 高带宽采集各模块电流
瞬态波形, 记录最大电流超调、是否震荡与均流恢复时间; 断路器合闸类冲击
负荷场景同理捕捉.

仪器链: 多通道同步功率分析仪/数据采集 + 每模块输出回路串接电流传感器
(精度等级不低于 0.5 级、瞬态响应良好) + 可编程直流电子负载. 各模块输出
电缆长度/截面应一致, 排除线路压降差异对均流的人为干扰(中析检测, CMA/CNAS
均流不平衡度试验方法说明).

**与需求层的边界**: 「不要求均流度」的型号(如 PA601-D54A SR-1219 备注)
不出判据行 —— 但备注同时要求「不能出现并联空满载切换带载」, 该要求属于
并联下电/再上电行为判据, 若作判据须另行确认验收口径, 不得借「均流」
名义出行.

## 温度系数测量与温度箱

温度系数判据(如 PA601-D54A SR-1217 ±0.02%/℃)的测量链与常规电参量判据
不同: 被测量本身不随激励变化, 变化的是**环境温度**, 所以「仪器」的承载者
是**能控温的环境腔**, 而不是读数的表.

温度箱能力口径(MIL-STD-810 试验 501.7/502.7 工作性高温/低温、GB/T
2424.7-2024 试验 A/B 温度箱带负载测量): 稳态控制与稳定度 ±0.5℃ 量级;
平均降温速率与本流程相关(常规领域 8℃/min 量级); 温箱必须**带载**运行 ——
DUT 按额定工况工作时的热负荷要落在腔体负载能力内, 且 DUT 位置的温度
梯度与稳定性要在判定不确定度内(GB/T 2424.7 即为此给出带负载测量导则).

测法: ≥3 个温度点(规格书工作温度范围两端 + 常温), 每点热浸稳定后
同步记录输出电压与 DUT 处温度; 温度系数用各温度点 (ΔV/V)/ΔT 做最小
二乘拟合. 读数用高分辨率 DMM(6 位半量级), 温度探针经巡检仪或 DMM
热电偶通道(T 型覆盖 −200~+400℃).

仪器清单(能力类别, 非型号): thermal chamber(程控、带载容量、±0.5℃ 稳定
度) + 高分辨率 DMM + 温度巡检/热电偶通道 + 程控接口 —— 需求推导层对
温度类 kind 应把 thermal_chamber 传播为仪器能力需求(漏它等于测不了).

  斜坡+终止电压判定; 可编程源/温箱触发; 打嗝/锁存与自恢复行为; 保护点精度)。
- 效率与热: M-EFFICIENCY(功率分析仪 V/I 同步采样, 25/50/75/100% 负载点取最小);
  M-TEMP-RISE(温箱+热电偶巡检; 关键点温升 <60℃ 级); M-KELVIN(四线开尔文, 毫欧计)。

  ≤100mΩ 或 ≤0.1Ω); M-TOUCH-CURRENT(泄漏网络 IEC 60990/GB/T 12113, 动/静态)。

仪表能力与指标须在同一工位口径下匹配: 仪器精度优于被测判据余量的 1/3; 通道数 =
ceil(产能 × 单次测试时间 / 可用工时); 全检工位优先"一次接线、一键跑完"的综合仪/

## 产测故障诊断与修复(输出/效率/热)

总原则: 先排除测试侧误判, 再判定 DUT 真故障; 用"分段隔离法"从输入→开关→输出逐段
定位; 与黄金样机对照; 记录现象/定位过程/更换件。

- 纹波噪声超标(M-RIPPLE-NOISE): 首要怀疑测法 —— 同一模块不同测法结果可差 8~10 倍
  (实例 600mV vs 73mV): ①探头长地线环路=天线, 感生噪声可达 V 级 → 用接地弹簧/靠接
  治具; ②带宽未限 → 20MHz 带宽限制; ③低纹波测量用 1:1 或 50Ω 同轴+阻抗匹配网络
  (行业标准做法, IPC-9592B / JEITA RC-9131B); ④环境检查: 探头尖端接自身地线测本底。
  真因排查: 输出电容 ESR 高/容量衰减(工频或倍频纹波→主滤波电容老化; 开关频率纹波→
  滤波/稳压元件老化); 电感值过小或饱和(ΔI 大); 电感漂移磁场耦合近旁回路; 环路相位
  裕度不足引发轻载低频纹波/大小波(模式切换点干扰被放大)。修复: 多级 LC 滤波+磁珠;
  换低 ESR 陶瓷电容(X5R/X7R); 提升相位裕度(增大补偿电容把零点移向 LC 双极点, 带宽
  取开关频率 5%~20%)后复测动态; 大小波→减小前馈电容 Cff/减小 Rfb/下分压并联
  500pF 降带宽; 物理上远离电感/加屏蔽。
- 输出精度偏高/偏低(M-REGULATION): 偏低 = 负载超带载能力或线路压降(线径过细、端子
  氧化)、输入电压不足、前级稳压器压差大、防反接二极管压降、稳压管老化、次级/反馈
  分压异常; 偏高 = 空载或轻于 10% 额定负载(稳压拓扑需 10% 假负载或换小功率型号)、
  输入电压偏高、滤波电容/整流二极管老化、变压器初级匝间短路(磁件饱和: 初级少绕或
  磁芯开裂)。修复: 校准基准/反馈网络; 换 LDO 或低压降肖特基; 规范最小负载; 磁件
  换料返修后按 M-TEMP-RISE 联动复测。
- 效率不达标(M-EFFICIENCY): 器件侧 = 开关损耗(高输入电压、过高频率)、磁芯损耗(高
  温激增, 选高居里温度磁材)、MOSFET Rds(on) 增大/驱动不足/死区不当、整流管压降;
  轻载效率低 = 静态电流占比大。测量侧 = 非正弦输入电流必须真有效值表/功率分析仪,
  V/I 通道相位校正(时延偏差)否则功率误差显著。修复: SiC/GaN 器件、同步整流、适度
  降频/优化磁材; 与温升复测联动。
- 动态过冲/恢复超标(M-TRANSIENT): 补偿网络不匹配、输出电容不足或 ESR 高; 修复: 调
  补偿(零点与带宽)使过冲 <5%/恢复 <1ms 级; 增输出电容时核对容性负载上限与启机过流
  风险; 复测 50%~100% 负载阶跃。
- 启动不良/欠压启动(M-STARTUP/M-UVLO/M-INRUSH): 输入源功率不足、前级内阻大(滤波
  电感/保险丝/线损)、缓启动电路失效(浪涌大或触发前级保护)、hiccup 打嗝(启动电阻/
  辅助绕组供电/VCC 电容异常)。修复: 换更大功率源、降内阻、检查缓启动回路。
- 温升超标(M-TEMP-RISE/M-BURN-IN): 磁芯饱和、MOS 导通损耗、散热界面(硅脂干枯/散热
  片松动)、风道积尘; 修复后按 40℃ 老化复测确认退化 <5%。

## 产测故障诊断与修复(保护/安规/通信)

- 保护误触/拒动(M-OVP/M-OCP/M-OPP/M-SCP/M-OTP/M-UVP): 比较器/基准阈值漂移(老化后
  高发 → 汽车级精密基准+温度补偿)、采样网络容差与噪声耦合、反馈回路开短路、容性
  负载过大导致启机过流误动(按规格电容组合复测)、打嗝/锁存逻辑确认。修复: 校准保护
  动作值与时序、更换漂移器件、加 RC 滤波抗扰。
- 过温保护异常(M-OTP): NTC 焊接不良、位置偏移、热阻不良; 快速判定: 万用表测阻值随
  加热是否变化, 不变化/无穷大即损坏。修复: 返修焊点与导热界面后复装机壳。
- 耐压不良(M-HIPOT): ①测法问题(首要): 耐压仪开机过冲与升压速率过快, 是模块内部
  高压 MLCC/绝缘损坏的常见外部原因(I=C·dV/dt 与寄生电感地弹使内部元件承受超压);
  按 GJB 360B-2009 方法 301 以 ~500V/s 缓升缓降, 禁用继电器/定时器切断电压, 必要时
  RC 缓冲网络或选可编程升压速率仪器; ②工艺: 回流焊温度过高/多次回流/热风枪维修使
  耐压下降(SMD 最多两次回流, 烙铁 <300℃ 且 <10s); ③材料结构: 爬电污染、灌胶空洞、
  匝间绝缘损伤。修复: 规范测试与焊接工艺参数, 换更高隔离电压型号, 按规范复测。
- 绝缘电阻低(M-INSULATION-RES): 潮湿/凝露(先干燥)、表面污染/助焊剂残留、内部介质
  空洞与应力裂纹; 判据示例 500Vdc ≥0.5MΩ(设备级)~100MΩ(模块级)按规格; 测试前须
  断开负载与二次回路防误击。修复: 清洁烘干、返修绝缘件。
- 接地/接触电阻超标(M-GROUND-BOND/M-KELVIN): 端子氧化松动、螺钉扭矩不足、压接不良、
  治具探针氧化; 四线开尔文排除线阻。修复: 打磨氧化层、按扭矩紧固、更换端子/探针。
- 泄漏电流超限(M-TOUCH-CURRENT): Y 电容选型漏电流偏大、绝缘退化、动/静态网络选择
  差异; 测试须隔离变压器浮接 DUT。修复: 换低漏电流 Y 电容、复核绝缘后复测。
- 遥测/通信异常(M-TELEMETRY/M-TELESIGNAL/M-TELECONTROL/M-COMM): 通信不通/误码 =
  终端电阻、地线环路、协议/波特率配置、隔离失效; 遥测偏差 = 校准系数漂移、基准温漂;
  告警点错 = 阈值配置与上报逻辑; 多路系统差频干扰 → 多路一体模块或重新布局, 敏感
  元件电源端 0.1µF 去耦、一点接地。修复: 重写校准系数/重配阈值, 复测误差留痕。
- 其余全检项典型失效速查: M-HOLDUP 不达标 = 输入侧储能容值衰减/规格不足、告警与
  跌落时窗配置错; M-PF 不合格 = PFC 电感饱和/电容老化或 APFC 控制失效, 谐波超标查
  桥堆与 EMI 滤波; M-INPUT-SLOW = 保护点/回差一致性(阈值迟滞设计); M-REVERSE-IN =
  防反接二极管/MOS 或保险丝开路; M-ORING = ORing 控制电路/二极管反向恢复; M-SHARE =
  均流采样偏差/下垂曲线/线阻不一致; M-POWERCYCLE = 循环后参数漂移(软启动/继电器寿命)。
- 间歇故障(偶发重启/电压波动): 虚焊/端子氧化、电网波动、EMI 干扰、电容容量衰减;
  排查: 紧固端子→检焊点→测电网波动→找干扰源→测电容容量; 修复: 重焊、加稳压与
  抗干扰滤波、换老化电容; 长期对策: 参数巡检台账。

## 产测故障定位通用流程与返修复验

- 分层原则(工业电源通行): 安全优先(停电验电、电容放电完毕再拆机)、先外后内(供电/
  线路/负载/环境 → 电源本体)、先简后繁(松动/跳闸/过载/积尘 → 器件级)、先静后动
  (外观静态 → 通电动态)、记录可追溯(全程台账)。
- 故障五分类: 完全无输出 / 输出参数异常 / 保护类 / 异常工况(异响/发烫/冒烟/风扇) /
  间歇故障。
- 四步定位法: ①外部排查(上级空开缺相、端子氧化虚接、地线、断开负载空载测试、环境
  温湿尘); ②空载静态(输入/空载输出/纹波/温度/保护指示); ③带载动态(逐路加载定位
  故障回路、额定与超载工况、温度噪声稳定性); ④拆机内部(保险丝/压敏电阻/电解电容
  鼓包/电阻烧断/整流桥与开关管击穿/驱动采样保护电路虚焊/硅脂与风扇)。
- 测试侧误判先排除: 探头方式(接地弹簧/1:1/50Ω 同轴+匹配网络)、20MHz 带宽、通道
  相位校正与探头消磁调零、负载模式与线损(远端 sense)、治具接触(开尔文)、黄金样机
  对照; 每日自检/仿真负载日检确认系统漂移。
- 批次性判定: 单点不良 → 个案返修并复跑完整工位; 批次不良 → SPC 图、来料批次与
  关键工序 CPK>1.67 管控; 关键退化判据: 老化后性能衰减 <5%、功率循环(ΔTj 80~120℃,
  10000 次)效率衰减 <2%; 系统性偏差 → 复查设计裕量(降额/环路/热设计)。
- 返修复验程序: 修复后空载通电 30min → 分级加载至满载运行 → 复跑完整工位(含安规
  例检) → 连续观察(工业口径 24h) → 记录归档(现象/定位过程/更换件), 更新 MTBF/MTTR
  等可靠性统计。
