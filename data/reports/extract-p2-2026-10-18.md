- `patterns.py`：映射表（`MEASURE_KINDS`/`TIMING_KEYS`）+ 单位换算（timing→ms / ripple→mVpp / efficiency→% / cap_load→uF / temperature→degC）+ `build_value` / `split_multi_value` / `rep_value` / `format_number` / `rail_of` / `scenario_bindings` / `note_input_conditions` / `baseline_input_voltage` / `extra_clauses` / `match_kind`（顺序敏感：timing 先于 output_voltage；纹波电流/相关性先验否决；监控三表按 scope 短路）。

- `narrative.py`：`NarrativeResult`；`select_blocks`（in-scope + length + 去重 + 截断留痕）；`_clause_from_item` 走 kind/side 词表闸门 + value fact guard（measure 整条弃，非 measure 仅弃值）+ method_ref 目录校验；`propose_from_blocks`（chunked 调 LLM，单 chunk 失败不阻断全局，落 review）；`build_requirements` 按源块分组 + `NAR-{product}-{seq:03d}` 编号 + `exclude_fingerprints` 去重；`extract_narrative` 一步式（LLM 未配 → 整体跳过）。

## 4. 关键设计口径（口径冻结，跨次运行逐位一致）

| 维度 | 口径 |
|------|------|
| 需求粒度 | 变体 = (SR 编号, 轨, 判据数值集) |
| 后缀消歧 | `-m{代表值}`（max 优先，否则 min）；仍冲突 → `-c{2..}` |
| grade 含「不要求」 | excluded, matched_word=「不要求」 |
| 非产测章节 | excluded, reason 含「非产测范围」 |
| measure kind 的 clause.value | 必须带 min/typ/max 至少其一，否则整条 review |
| 输入侧条件 | 原文数值 > 产品基线（基线取自「输入工作电压范围/交流输入电压范围/工作电压」） |
| 输入基线 CY | min=85, typ=220, max=300, unit=Vac |
| 输入基线 GDC | min=36, typ=48, max=60, unit=V |
| 输入基线 PA601 | min=88, typ=220, max=290, unit=Vac |
| LLM 提案红线 | status='draft' / source='narrative' / confidence='llm' |
| 需求编号（spec） | `SR-{product_code}-{table_id}-{row_index}`（无原始编号时合成）或 `{SR-num}-m{rep}` / `-c{n}` |
| 需求编号（narrative） | `NAR-{product_code}-{seq:03d}` |
| 导入幂等键（消费侧） | `(product_code, requirement_code)` / `(owner, cond_fingerprint)` |
| bundle_fingerprint ignore | `generated_at` + `bundle_fingerprint` 自身 |
